# Мягкие проверки норм для эскиза

Каждое правило — подсказка со ссылкой на пункт; помечено «норма» или «ориентир». Окончательно проверяет проектировщик. Часть пунктов (СП 44, глубина тамбура) требует сверки с актуальной редакцией.

| Проверка | Правило | Источник |
|---|---|---|
| Универсальная кабина с/у МГН | В чистоте не меньше 2,20×2,25 м, круг разворота Ø1,4 м, дверь открывается наружу. Кабину 1,70×2,20 принимать, только если универсальных кабин несколько (прим. 3). При наличии с/у для посетителей — хотя бы одна универсальная кабина. Красное. | СП 59.13330.2020, табл. 6.1, п. 6.3.2–6.3.3 (текст: https://github.com/Akumsk/russian-construction-standards) |
| Двери на пути МГН | Входные двери и дверь универсальной кабины: в свету ≥ 0,9 м; у двустворчатой одна створка 0,9. Внутренние двери на пути МГН: полотно ≥ 0,9. Порог ≤ 0,014. Ширина в свету = полотно − 0,05 на створку. | СП 59.13330.2020 п. 6.1.5, п. 6.2.4 |
| Ширина клиентского пути МГН | Меньше 1,8 м — жёлтое «нужны карманы 1,8×2,0 м в пределах видимости»; меньше 1,2 м — красное; высота прохода ≥ 2,1 м; поворот 1,2×1,2, разворот Ø1,4. | СП 59.13330.2020 п. 6.2.1 |
| Тамбур | Глубина по ходу движения ≥ 2,45 м, ширина ≥ 1,6 м (жёлтое, пометка «сверить редакцию»). Тамбур на пути эвакуации шире проёма на 0,5 м, глубина ≥ 1,5, траектории дверей не пересекаются. | СП 59.13330.2020 п. 6.1.8 (по дайджесту, уточнить); СП 1.13130.2020 п. 4.3.11 |
| Ширина путей эвакуации | Горизонтальный путь ≥ 1,0 м; ≥ 1,2 м при > 50 эвакуирующихся; 0,7 м к одиночным рабочим местам. Вычитать половину или всё полотно двери, открывающейся в коридор. Высота пути ≥ 2,0 м. | СП 1.13130.2020 п. 4.3.3–4.3.4 |
| Эвакуационные выходы (двери) | Ширина в свету ≥ 0,8 м; ≥ 1,2 м при > 50 чел.; 0,6 м допустимо для санузлов, кабин и кладовых ≤ 20 м² без постоянных мест. Высота ≥ 1,9 м (1,8 без постоянного пребывания). У двустворчатой считать только активные створки (флаг bothActive). | СП 1.13130.2020 п. 4.2.19, п. 4.2.18, п. 4.2.24 |
| Направление открывания | Двери эвакуационных выходов из помещений на > 15 человек открываются по направлению выхода; жёлтое «проверьте направление». | СП 1.13130.2020 п. 4.2.22 |
| Численность и второй выход | Численность считать по площади: Ф4.3 — площадь офисных помещений / 6 м²; Ф3.5 — площадь зоны посетителей / 1,35. Мебель и «эвент-режим» — дополнительный расчёт, берётся большее значение. Второй выход нужен при ≥ 50 чел. в помещении с учётом помещений, выходящих через него, или при > 25 м до выхода. Формулировка «нужен второй выход — уточнить у проектировщика». Класс Ф4.3/Ф3.5 определяет проектировщик. | СП 1.13130.2020 п. 4.2.7, п. 7.13.2, п. 7.13.3, п. 7.10.1; 123-ФЗ ст. 32 |
| Рассредоточение выходов | Расстояние между ближайшими гранями выходов из помещения ≥ ½ максимальной диагонали; в коридоре > 0,4 длины коридора. | СП 1.13130.2020 п. 4.2.16 |
| Доля антресоли | Площадка / базовое помещение (выбирает пользователь) < 40%. Показывать формулой; 35–40% — жёлтое, ≥ 40% — красное «может считаться этажом — подтверждает проектировщик». | СП 118.13330.2022 п. 3.1.2 |
| Высоты при антресоли | Высота зала в чистоте ≥ 4,7 м; проход под и над антресолью ≥ 2,2 м (красное). Закрытые административные помещения на антресоли ниже 2,7 м — жёлтое. | СП 118.13330.2022 п. 4.26, п. 4.27 |
| Ограждение перепада | При перепаде отметок пола > 1,0 м ограждение ≥ 1,2 м. | СП 118.13330.2022 п. 6.12 |
| Лестница на антресоль | Марш ≥ 1,2 м (0,7 при эвакуации ≤ 5 чел.); высота пути по лестнице ≥ 2,2 м; ≤ 18 подъёмов в марше; уклон ≤ 1:1; для посетителей подступенок 0,13–0,17; промежуточная площадка ≥ 1 м. | СП 1.13130.2020 п. 4.4.1, п. 4.4.4; СП 118.13330.2022 п. 5.7, 5.10, 5.11 |
| Один выход с антресоли | Одна лестница допустима, если площадь антресоли ≤ 300 м² и на ней ≤ 20 чел.; иначе красное. | СП 1.13130.2020 с изм. 1 (https://78.mchs.gov.ru/uploads/resource/2023-12-27/izmeneniya-1-k-svodu-pravil-sp-1-13130-2020-sistemy-protivopozharnoy-zashchity-evakuacionnye-puti-i-vyhody_17036645221069199865.pdf) |
| Клиентская функция на антресоли | Блок или помещение зоны «публичная / полупубличная / закрытая клиентская» на уровне 1 — жёлтое «нужен подъёмник для МГН». Проверка строится по зоне приватности, а не по категории meet. | СП 59.13330.2020 (доступность уровней); методика |
| Рабочее место с ПК в бэк-офисе | Площадь / число мест < 4,5 м² — жёлтое; < 6 м² — информация «тесно». Помечено как рекомендация, не норма. | МР 2.2.0244-21 к СП 2.2.3670-20 (ориентир) |
| Кабинет приёма и руководителя | Кабинет менеджера с индивидуальным приёмом < 12 м² — жёлтое; кабинет руководителя < 18 м² — информация. Рекомендация. | СП 118.13330.2022 п. 5.31 |
| Санузлы персонала и посетителей | Число приборов раздельно для персонала и посетителей; ×1,5 при общих санузлах; один общий с/у допустим только при ≤ 10 сотрудниках и ≤ 10 посетителях; мастер спрашивает состав по полу. | СП 118.13330.2022 п. 5.54, п. 5.60 |
| Комната приёма пищи | Численность в смене до 30 чел.: 1 м² на человека, не меньше 12 м²; при ≤ 10 чел. допускается место 6 м² (пометка «сверить»). | СП 44.13330.2011 пп. 5.51–5.52 |
| Пандус (если есть перепад у входа) | Уклон > 80‰ — красное; 50–80‰ — проверять длину марша по таблице; до 100‰ только при перепаде ≤ 0,2 м на входе. | СП 59.13330.2020 табл. 5.1, п. 6.1.2 |
| Геометрия плана | Пересечение помещений без sub/parent; объект за контуром здания; проём не на стене (needsHost) или не помещается; зазор стыка ≠ толщине перегородки (tight/gap из edges()). | Внутренняя логика модели v2 (ориентир) |
| Выполнение программы | Неразмещённые строки; отклонение помещения больше допуска (по умолчанию ±5% зелёный, 5–15% жёлтый, > 15% красный); «вне программы»; Σ цели × k > площади уровня. | Snaptrude Area Dashboard https://help.snaptrude.com/en/articles/10319139-area-dashboard (ориентир) |
| Связи | Нарушена пара «обязательно рядом» (нет общего стыка и > 1,5 м между гранями) — красное; общий стык в паре «нельзя рядом» — красное. | Упрощённый Muther SLP / VantageSpace (ориентир) |
| Эргономические ореолы | Стол переговоров до стены < 0,9 м; обход макета < 1,2 м (минимум 0,9); перед медиастеной < 2·h экрана; за спиной сидящего с проходом < 1,0 м — жёлтое. | Neufert / Panero & Zelnik (ориентир, не норма) |

Автоматически в `KB.checks()` реализованы: кабина МГН 2,20×2,25; глубина тамбура 2,45; высоты при антресоли (зал ≥ 4,7; под и над ≥ 2,2); доля антресоли 35/40%; антресоль > 300 м² → вторая лестница; лестница есть; клиентское на антресоли → подъёмник МГН; ограждение антресоли; 4,5 м² на рабочее место в бэк-офисе; кухня ≥ max(12, штат); кабинет приёма < 9 м²; ширина коридоров 1,2 / 1,5–1,8; выход за контур; перекрытия помещений; программа цель/факт.
