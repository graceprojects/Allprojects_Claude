# Формат файла проекта «Планировщика офиса продаж»

Файл — JSON. Открывается в планировщике: «Проекты» → «Открыть файл…». Генерируется `scripts/generate_office.js`, проверяется `scripts/check_project.js`.

## Система координат

- Метры. X — вдоль дороги (0…b.w), Y — вглубь участка сверху вниз (0…b.d). **Y = b.d — витражный фасад у дороги** (низ плана).
- Наружные стены 0,3 м рисуются внутрь контура: внутренние грани x = 0,3 и b.w−0,3, y = 0,3 и b.d−0,3.
- Колонны витража — с шагом 5 м по X (0, 5, 10…). Вход ставят по оси пролёта (2,5 + 5k), чтобы не попасть на колонну.
- lv: 0 — первый этаж, 1 — антресоль на отметке b.mz (обычно 3,3).

## Корень

```json
{ "v": 1, "name": "Офис продаж ЖК …", "notes": "пожелания для ТЗ",
  "b": { "w": 40, "d": 12, "h": 7, "mz": 3.3, "front": "vitrage" | "wall" },
  "items": [ …помещения, стены, мебель… ],
  "program": [ { "key": "cabinet", "name": "Кабинет менеджера", "zone": "semi", "cat": "office", "n": 6, "area": 9.6, "status": "обязательно", "rule": "…", "sub": false } ],
  "meta": { "params": { …параметры генератора… }, "warnings": [] } }
```

## Помещение (t: "room")

```json
{ "id": "r1", "t": "room", "lv": 0, "name": "Кабинет менеджера", "x": 4.3, "y": 0.3, "w": 3.0, "h": 3.2,
  "cat": "office", "border": "glass", "color": "#9EA3A6", "sub": false, "ph": 3.0 }
```

- `cat` (цвет и итоги): client, office, meet, back, staff, service, wc, circ.
- `border`: none (зона без стен), wall (ГКЛ/блок), glass (стеклянные перегородки). `ph` — высота перегородок, м.
- `sub: true` — зона внутри другого помещения (ресепшен, макет, детская, ожидание, тамбур в зале): рисуется пунктиром, в итог площади не входит.
- Площадь = w × h. Номера в экспликации присваиваются автоматически. `program` сопоставляется с помещениями по названию (см. MATCH в office-kb.js), поэтому держите стандартные названия.

## Стена (t: "wall")

```json
{ "id": "w1", "t": "wall", "lv": 1, "kind": "rail", "x1": 27.3, "y1": 0.3, "x2": 27.3, "y2": 5.3, "th": 0.05 }
```

| kind | название | толщина, м | высота |
|---|---|---|---|
| ext | Наружная стена | .3 | "H" |
| block | Стена (газоблок) | .2 | "H" |
| part | Перегородка ГКЛ | .1 | 3.0 |
| glass | Стеклянная перегородка | .1 | 3.0 |
| vitrage | Витраж | .15 | "H" |
| rail | Ограждение h 1.1 м | .05 | 1.1 |

## Мебель и оборудование (t: "item")

```json
{ "id": "f1", "t": "item", "lv": 0, "k": "work3", "x": 5.0, "y": 0.7, "w": 1.6, "h": 2.3, "rot": 0, "flip": false, "label": "" }
```

- x, y — левый верхний угол **габарита на плане** после поворота; w, h — собственные размеры предмета (ширина × глубина).
- rot: 0 / 90 / 180 / 270 (по часовой). При rot 0 «спинка» или петли двери — сверху (−Y), фасад предмета смотрит вниз (+Y, к витражу).
- Двери: k = door9/door10/door18; полоса стены 0,3 м сверху, створка открывается вниз. h = ширина створки + 0,3. Двери лучше ставить через функцию door() в office-kb.js.
