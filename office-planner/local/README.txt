Планировщик офиса продаж — локальная версия

WINDOWS (ничего устанавливать не нужно)
  1. Распакуйте архив (правой кнопкой > «Извлечь всё»). Не запускайте прямо из zip!
  2. Дважды щёлкните start-windows.bat.
  3. Откроется чёрное окно и браузер с адресом http://localhost:8080
     Окно НЕ закрывайте, пока работаете: это и есть сервер.
  Если порт 8080 занят, будет выбран 8081…8090 — адрес написан в чёрном окне.
  Если Windows показала «Windows защитила компьютер»: «Подробнее» > «Выполнить в любом случае».

macOS / Linux
  В терминале в этой папке: ./start-mac-linux.sh  (нужен python3 — на Mac он обычно есть)

БЕЗ СЕРВЕРА
  Просто откройте index.html двойным щелчком — всё работает так же.

Проекты сохраняются в браузере этого компьютера (кнопка «Проекты»).
Резервная копия и перенос: «Выгрузить» > «Файл проекта»; открыть: «Проекты» > «Открыть файл…».
Проекты привязаны к адресу: через localhost:8080 и через двойной щелчок списки разные.
